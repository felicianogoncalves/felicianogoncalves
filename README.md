# Hi, I'm Feliciano

**Systems Administrator moving into DevOps and Cloud** · Portugal

I run infrastructure for clients at a Managed Service Provider: Microsoft 365, firewalls, backups, virtualization and Windows Server. Before IT, I spent more than 10 years in industrial automation and electronics, working with machine vision, drives and maintenance on production lines.

Now I'm building the skills to automate what I used to do by hand: containers, CI/CD pipelines, infrastructure as code and Kubernetes.

**Right now**
- Preparing for the **CKA** (Certified Kubernetes Administrator) on a 3-node kubeadm cluster at home
- Building an on-prem CI/CD lab: GitHub Actions, GHCR, rootless Podman with Quadlet, and monitoring with Prometheus, Loki and Grafana
